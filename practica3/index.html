  1. Existen dos formas principales de conectar un archivo HTML con JavaScript. Explique cuáles son estas 2 formas y proporcione un ejemplo básico de cada una.

    2. Estas dos formas son:


    • Código Interno: Se escribe el código de JavaScript directamente dentro de un archivo HTML utilizando la etiqueta < script >, por lo general colocada justo antes de cerrar el cuerpo < /body >.
      Ejemplo; 
                              
                            < script >
                                code.log("hola desde JavaScript interno")
                            < script >
    • Código Externo: Se escribe el código en un archivo independiente con extensión .js (por ejemplo, script.js) y se vincula al archivo HTML mediante el atributo src de la etiqueta < script >. Esta es la práctica más recomendada para mantener el código organizado.
      Ejemplo: 
                              
                        < script src = "script.js" > </script >

  2. Explique paso a paso cómo visualizar los resultados de JavaScript utilizando la consola del navegador.

    3. La consola del navegador es una herramienta esencial para desarrolladores. Para ver los resultados impresos con funciones como console.log():

    1. Abre tu archivo HTML en cualquier navegador web moderno (Chrome, Firefox, Edge, etc.).
    2. Abre las Herramientas de Desarrollador (DevTools) haciendo clic derecho en cualquier parte de la página y seleccionando Inspeccionar, o utilizando los atajos de teclado:
      • Windows/Linux: F12 o Ctrl + Shift + I
      • Mac: Cmd + Option + I
    3. Busca y haz clic en la pestaña Consola (Console en inglés).
    4. Allí podrás visualizar los mensajes enviados desde tu código y también escribir comandos de JavaScript de forma interactiva.

  3. Explique qué son las variables en JavaScript y cuál es la diferencia entre var, let y const. Incluya un ejemplo sencillo de cada una e indique cuál de estas formas ya no se recomienda utilizar actualmente y por qué.

    4. Una variable es un contenedor simbólico para almacenar datos (como textos, números o booleanos) que se pueden reutilizar y manipular a lo largo del programa.

    Diferencias entre declaraciones:
    • var: Es la forma tradicional. Tiene un ámbito de función (function scope), permite reasignar valores y redeclarar la variable, lo que puede causar errores inesperados.
    • let: Introducida en ES6. Tiene un ámbito de bloque (block scope), permite reasignar su valor, pero no permite redeclararla en el mismo bloque.
    • const: También introducida en ES6. Se utiliza para constantes; su valor es fijo una vez inicializado, por lo que no se puede reasignar ni redeclarar.

    Ejemplos:

                var nombre = "Ana";
            let edad = 25;
            const pais = "México";
